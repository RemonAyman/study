# 🎯 منصتي للمذاكرة | متراكم الثانوية العامة والملاحظات

منصة ويب متطورة وسلسة مخصصة لمتابعة المتراكم الدراسي، تنظيم المذاكرة لطلاب الثانوية العامة، تسجيل الملاحظات ومواعيد الامتحانات القادمة، مع نظام تحفيزي متكامل بمؤثرات صوتية واحتفالية لحظية عند إنجاز أي درس.

---

## 🌟 مميزات المنصة

- 🧪 **المواد الدراسية الست الأساسية**:
  - **كيمياء**: ثيم الزمرد المشع، نصائح خاصة بمعادلات العضوية والكيمياء الكهربية.
  - **فيزياء**: ثيم الأزرق الكهربي، نصائح خاصة بقوانين كيرشوف والدوائر ورسم البيانات.
  - **أحياء**: ثيم النعناع الحيوي، نصائح المناعة والـ DNA.
  - **لغة عربية**: ثيم العنبر الدافئ، التركيز على النحو وقواعد الإعراب والبلاغة.
  - **لغة إنجليزية**: ثيم البنفسج الملكي، الكلمات والقواعد وقطع الفهم.
  - **جيولوجيا**: ثيم الفيروز، علوم الأرض والقطاعات الجيولوجية.

- 📋 **جدول المتراكم المخصص لكل مادة**:
  - خانة سريعة لتسجيل اسم الدرس أو الجزء المتراكم.
  - تصنيف نوع المذاكرة (شرح، حل تدريبات وشيت، مراجعة وتثبيت، تلخيص، امتحان جزئي).
  - تحديد الأولوية (طارئ وعاجل 🔴، متوسطة 🟡، هادي في وقته 🟢).
  - زر الإنجاز السريع (علامة صح تفاعلية).

- 🎉 **نظام الاحتفال والتحفيز (عاااش مووووت!)**:
  - بمجرد الضغط على علامة الصح، تنطلق مفرقعات الزينة والكونفيتي المبهجة (`canvas-confetti`).
  - عزف نغمة إنجاز حماسية احتفالية تلقائياً عبر `Web Audio API`.
  - تظهر رسالة الاحتفال الكبرى: **"عاااش مووووت! فخور بيك يا بطل.. كمل متوقفش! 💪"**
  - إزالة الدرس المنجز من جدول المتراكم، مع وجود سجل أرشيف للإنجازات يمكن مراجعته أو استرجاع أي درس منه.

- 📝 **قسم الملاحظات ومواعيد الامتحانات**:
  - تسجيل مواعيد امتحانات السناتر والشوامل.
  - عداد تنازلي ذكي للأيام المتبقية على الامتحان (مثال: "باقي 5 أيام ⏳"، "اليوم! 🚨").
  - تسجيل ملاحظات المستر وتنبيهات الشيتات والواجبات.

- ⏱️ **مؤقت بومودورو للتركيز الذكي (Pomodoro)**:
  - جلسات مذاكرة 25 دقيقة واستراحة 5 دقائق لتثبيت التركيز.

- 🌙 **تصميم مريح جداً للعين (Eye-Friendly Design)**:
  - نمط ليلي داكن فاخر (Midnight Obsidian).
  - زر تفعيل "حماية العين الدافيء" (Warm Glow Filter) المخصص للمذاكرة الليلية الطويلة.
  - خط عربي عصري أنيق (Cairo) من Google Fonts.

- ☁️ **تكامل مع Google Firebase Cloud Firestore**:
  - حفظ لحظي (Real-time Sync) لكافة المهام والملاحظات.
  - نظام دعم دون اتصال (Offline-first Fallback) لضمان العمل تحت أي ظرف.

## 🔒 قواعد أمان Firebase Firestore (Security Rules)

لتفعيل حفظ وقراءة البيانات سحابياً في فايربيز، افتح مشروعك في [Firebase Console](https://console.firebase.google.com/)، ادخل على **Cloud Firestore** ثم تبويب **Rules** وضع القواعد التالية:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // السماح بالقراءة والكتابة لكافة بيانات المتراكم والملاحظات
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

ثم اضغط على زر **Publish**.
